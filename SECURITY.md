# Security

Please do not report vulnerabilities in public issues. Email [wafffllesss@gmail.com](mailto:wafffllesss@gmail.com) or use GitHub's private vulnerability reporting when it is enabled for this repository. Include the affected version, reproduction steps, impact and any proposed mitigation. The maintainer will review the report and coordinate disclosure; no response-time guarantee is currently available.

The latest release is the supported version. This is a casual game, not an anti-cheat system: clients interpret game actions and a modified client can bypass application-level checks. Protect Firebase resources with Security Rules and server-side authorization; Firebase Web configuration is visible in the distributed client and is not a secret. Never put server credentials or TURN shared secrets in client configuration or issue reports.
